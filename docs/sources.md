# Sources and scope

The companion's prose, examples, distractors, and feedback are original instructional material. It does not reproduce the textbook. It is an independent companion, not an official Edmonds or Cambridge publication.

Conceptual reference for lesson 1:

- Jeff Edmonds, *How to Think About Algorithms*, opening iterative-algorithm and loop-invariant treatment. We do not assign page numbers without checking the reader's edition.
- [Actions vs. Assertions](https://www.youtube.com/watch?v=cnibtOFooFg), linked as a primary lecture reference, with the user's existing study notes used to orient the draft.
- [Loop-invariant handout](https://www.eecs.yorku.ca/~jeff/courses/2101/notes/HowToThinkAboutAlg~LoopInvariants.pdf): contracts, preservation, establishment, exit and termination.

## DFA opening draft

Reading connection: second edition, section 2.2, page 35, opening material through Applications and Features, excluding Example 2.2.1. Verified against the [publisher/distributor preview](https://api.pageplace.de/preview/DT0400.9781009302166_A49238670/preview-9781009302166_A49238670.pdf). The companion adds original alphabet examples, an ends-in-1 language, two original SVG diagrams, notation matching, and misconception checks. It does not copy the book's worked example.

Review audience: high-school students without prior automata or set-theory knowledge. The 20-minute estimate is provisional. The opening introduces prefix explicitly; the full DFA tuple and regular-expression syntax are deferred. The lesson is still a draft awaiting teacher review and student trial.
